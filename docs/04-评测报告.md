# AGNES Arena 评测报告

## 本轮结果

10 个模型两两配对，完成 45 组换边、90 场有效对局。每个模型与其余 9 个模型各打两场，共 18 场。平均每局 10.40 回合。本轮模型调用估算投入约 **3062 元**，逐调用记录覆盖全部尝试。

这轮实验评估的是：在相同工具、固定对战环境和共同 Jev 辅助下，模型能否完成长程任务，以及最终对战表现。动画只负责展示；引擎产生胜负，会话记录证明执行过程。

## 实验设置

| 项目 | 设置 |
| --- | --- |
| 对战规则 | 第九世代自定义单打、双方各 3 只、等级 50 |
| A 队 | 皮卡丘、喷火龙、妙蛙花 |
| B 队 | 水箭龟、耿鬼、快龙 |
| 种子 | `[10, 3, 20, 26]` |
| 配对控制 | 队伍固定在 A/B 座位，第二场交换模型的座位 |
| 用户任务 | 每局每方只发送一次整局任务 |
| 工具 | observe、evaluate、act、feedback、wait 五个原生 AGH 工具 |
| 辅助模型 | 所有模型统一使用 Jev-1.13.0；多个合法候选必须有真实回执 |
| 上下文与输出 | 128000 上下文窗口；8192 单次输出预算 |
| 回合上限 | 40 回合，未分胜负由引擎结算平局 |
| 时间协议 | 初期 40 分钟；后续补跑为 2 小时，分别保留协议记录 |
| 峰值并发 | 实际记录为 24 场；实现支持设置 1–32 场 |

参数详见原始 `protocol.json`、`protocol-v2.json` 及各场 `battle.json`。由于补跑时限放宽，不将所有尝试描述为完全一致的时间预算。

## 如何选择计分比赛

每一组配对只取**最早通过核验的完整两场换边组**。不能拼接不同尝试中的单场，也不能根据胜负挑选重试结果。技术失败不记作模型败局；原始失败、取消、补跑和其消耗均保留。

归档共有 282 次比赛尝试、564 份双方原始会话文件。90 场计分比赛对应 180 份完整会话。本轮核验这些会话合计 185020 条原始事件、9681 次工具调用：每方一个整局用户任务、一次任务启动、连续事件序号和正常完成终止记录均通过。

核验文件：[本次核验](../evidence/history/本次核验.json)、[有效90场](../evidence/history/有效90场.json)、[有效180会话](../evidence/history/有效180会话.json)。全部尝试仍见原始轨迹索引。

## 模型请求名称与身份

公开展示使用统一名称，例如 DeepSeek-V4.1-Flash。原始 API 请求名、回执名另存于技术文档与轨迹中。
本榜单比较的是**本次请求配置**；第三方网关别名不等于独立核实的模型权重版本。Gemini 请求名为 `gemini-3.8-flash-high`，回执标识出现 `gemini-3.8-flash-n`，这一映射尚未独立证实。

## 结果的适用范围与下一步

换边控制了模型使用两套固定队伍的机会，但没有消除单一种子、固定阵容、网关差异以及样本量有限的影响。本轮榜单不能推导为通用模型能力排名。

不带 Jev 的 90 场消融**尚未运行**。后续将保留相同配对、队伍、种子、提示与预算，仅关闭辅助评估，比较胜率、完成率、动作质量、回合数、耗时和费用。进一步评测可采用多个成对种子和多套预先固定阵容；先固定实验方案，再开始调用。
