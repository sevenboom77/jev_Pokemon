# 复现说明

## 一、直接阅读文件

解压后先打开根目录的 [文件列表](../00-文件列表.md)。说明材料都是独立 Markdown 文件，可用支持 Markdown 的编辑器阅读；视频直接打开 [完整 MP4](https://fileditchvids.st/balpha30/eb3b5ddfba66a7968b8c/G003_project_demo.mp4)。

核对一局的过程时，打开 [90场阅读索引](../evidence/history/阅读索引.md)，选择 A/B 方的会话阅读稿。每份阅读稿按原始时间和事件序号列出用户任务、模型输出、工具输入输出、调用用量与终止记录，并链接对应原始 JSONL。

阅读已有文档、会话和视频，无需启动服务、安装依赖或填写模型密钥。

## 二、核对已完成比赛

`evidence/history/有效90场.json` 列出计分比赛；`有效180会话.json` 将模型、座位、会话 ID 与原始文件一一对应。`阅读索引.md` 可直接跳转原始文件。

全部尝试索引保留在 `evidence/history/evidence/league-jev-20261004/trajectory-index.json`，包含 282 次尝试。每个尝试在 `evidence/history/runs/<matchId>/` 中保留原始记录。原始索引里的本机绝对路径和 localhost 工作台链接是实验发生时的入口；移机阅读使用本材料的新相对索引。

有效比赛记录包含 90 场、180 个会话；每方以一个整局任务持续运行，事件序号连续，末次 `turn/end` 的 `reason=completed`。计分场次与会话的对应关系见上述比赛和会话索引。

## 三、源码安装与无付费测试

以下命令从解压后的根目录开始执行。

环境：Node.js 24.10–24.x，本机核对版本为 24.21.0。AGH 源码工作区固定使用 pnpm 10.34.5。评审只看材料时不需要安装这些依赖。

```sh
cd agnes-harness
pnpm install --frozen-lockfile
cd ../pokemon
npm ci --ignore-scripts
npm run battle:build
npm run battle:test
npm run jev:test
```

构建使用随附的固定版本 Showdown Client 源码，不依赖其 `.git` 目录。测试使用规则引擎与受控本地响应，不启动付费对局。实际通过数量见 `docs/original-tests/本次测试结果.json`。

交付包含 AGH 框架源码，以及本轮联赛所用的代码运行时。上面的 AGH 工作区安装步骤也为 TypeScript SDK 辅助脚本提供依赖。

随附 `.runtime/battle-agh-runtime/` 为 macOS 运行时，含平台原生辅助程序。其他平台需要从随附源码重建：

```sh
cd ../agnes-harness
pnpm --filter @agnes/cli build:local
```

生成路径为 `agnes-harness/packages/cli/dist/local/`。本轮联赛另有历史恢复和超时补丁，详见技术文档第 7 节和 `02-源码/交付适配说明.md`。跨平台重建后运行时是否完整等价，仍需针对重建版本单独验证；不把已有 macOS 验证视作跨平台验证。

## 四、重新启动一场真实对战

以下步骤在 `pokemon` 目录中执行，会使用自己提供的模型与 Jev 额度。不要为阅读已有材料执行它们。

```sh
cp .env.example .env
```

填写 `.env` 中的 AGNES 地址与密钥、模型网关地址与密钥、`TYPESAFE_API_KEY`。`models.example.json` 保留这轮实验的请求配置；需要相应网关确实支持这些别名，不会自动替换成其他模型。

```sh
npm run battle:build
npm run battle:live
```

初始化只在当前项目的 `.runtime/` 中创建独立配置，不修改全局 AGH 或 Claude Code 的账号。默认对战端口为 18795，传输端口为 18796，双方工作台端口为 18781 和 18782。

服务显示双方玩家就绪后，另开两个终端，在 `pokemon` 中运行：

```sh
node --env-file=.env scripts/battle-web.mjs A
node --env-file=.env scripts/battle-web.mjs B
```

打开对战页 `http://127.0.0.1:18795/`，选择 A/B 模型、保留 Jev 勾选，点击“开始对战”。页面链接可进入各自原生 AGH 工作台，默认显示实际绑定模型的对话。玩家会从一个整局任务持续调用工具，完成后保存到 `runs/`。

默认真实对战是单场演示，不自动启动 90 场联赛。本次整理材料没有新发起付费比赛，也没有运行不带 Jev 组。

## 五、预期行为与故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 页面只有文字或素材缺失 | 通过 HTTP 打开；检查 Showdown 素材网络访问 |
| 工作台没有比赛会话 | 打开对应独立 A/B 工作台，不是个人全局 AGH 后台 |
| 401 | 核对自己的网关地址、接口、密钥和账号授权 |
| 429 或长等待 | 降低比赛/渠道并发，检查额度与退避回执 |
| 动画终局但 AGH 未正常完成 | 查看双方 `turn/end`、任务结果与历史核验，不纳入有效榜单 |
| 状态变更后提交失败 | 模型须重新观察当前决策编号和合法候选 |
| Jev 评估失败 | 保留原始错误；不能在带 Jev 组中用本地建议替代真实回执 |

已完成对局包含模型随机性与第三方服务状态；复现代码和实验设置不保证新比赛产生相同胜者。
